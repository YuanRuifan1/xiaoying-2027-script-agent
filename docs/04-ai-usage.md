# AI 辅助与个人贡献记录

本项目允许 AI 辅助，以下记录按实际已发生事项填写。

| 工作 | 已发生的贡献 | 验证情况 |
|---|---|---|
| 选题与范围 | 候选人提供题目并选择第 4 题；AI 提出实现方案 | 候选人在对话中确认 |
| 产品资料 | 候选人选择合成短视频编辑产品；AI 编写虚构资料 | JSON 可直接审阅，不代表真实产品 |
| 模型接入 | 候选人提供本地配置并要求优先免费模型；AI 查阅智谱官方文档并实现适配 | 真实结果见 examples/runs/glm |
| 代码 | AI 生成首版代码、测试、CLI 和后续修正 | 自动测试报告与真实运行记录可核验 |
| 文档 | AI 根据实际实现和运行结果整理 | 候选人仍需亲自审阅 |
| GitHub | 候选人指定账号及公开可见性并完成官方登录授权；AI 创建仓库和整理 Git 提交 | 公开仓库 YuanRuifan1/xiaoying-2027-script-agent，最终 SHA 以远程核验为准 |

候选人尚未在本记录中声明独立实现算法、亲自执行全部测试或逐行理解全部代码；不能据此声称这些贡献。提交前应由候选人阅读核心循环、检查器和 Trace，亲自复现，并把实际修改及复现结果追加到本文件。

AI 主要帮助：需求拆分、工程实现、测试设计、运行故障分析及文档。AI 输出不能自动视为正确：采用可执行测试、失败注入、版本哈希与真实模型记录核验。

没有把预设 Mock 策略当成模型决策证据；没有提交模型内部思维过程。真实模型的 action reason 是一句简要依据。密钥仅在本地 `.env` 或环境变量使用，不属于交付材料。
